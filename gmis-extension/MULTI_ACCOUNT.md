# 同一控制台多账号

0.3.0 已改为 **扩展控制台 + 本机后台**。不需要每个账号一份 Chrome 配置，也不需要在普通学校标签页里反复切换登录。

| 操作 | 位置 |
| --- | --- |
| 启动多账号后台 | `gmis-helper/start-helper.cmd` |
| 配对 | 控制台顶部，粘贴后台本次生成的配对码 |
| 添加学号、密码 | 左侧「自动登录设置」 |
| 选择批量运行账号 | 勾选左侧账号列表 |
| 查看一个账号的项目 | 点击该账号，再获取项目列表 |
| 为多个账号按部分名称匹配 | 选择类别和关键词，点击「为勾选账号匹配项目」 |
| 开始 | 「启动勾选账号」 |
| 停止 | 「停止当前账号」或「停止全部」 |

每个账号拥有独立 Cookie、登录页面和请求上下文。不同账号任务并行；同一账号最多并发两个列表查询，验证码到提交核验依次执行；本地 OCR 识别共享队列。登录后从学校主页读取实际学号，必须与配置学号一致。

选择「全部：劳动实践 + 学术报告」可同时查看并勾选两类的多个项目。已选项目独立计时，切换筛选不会覆盖选择；到点项目轮流尝试，最多尝试次数为账号全部项目共用上限。

开始时间空白默认项目报名开始前 1 分钟，也能手动输入。重试间隔最小 0.01 秒，指失败后的等待；完整循环仍需要网络和 OCR 时间。

已有旧版：停止任务，重新加载扩展，关闭旧页面，重新点击扩展图标。打开的应为 0.4.2「多个账号，一个控制台」页面。关闭并重新启动后台后重新配对、添加账号。默认选择「统一身份认证（校园门户）」，填写统一身份认证密码；后台会依次完成统一认证、进入 校园门户、打开研究生系统并核对 GMIS 学号。详细说明见 README.md。
